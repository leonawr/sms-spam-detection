
# SMS Spam Detection

## О проекте

Учебный проект по машинному обучению, направленный на автоматическое выявление нежелательных и потенциально опасных текстовых сообщений (спама).

Цель проекта — разработать и сравнить модели машинного обучения для классификации SMS-сообщений на две категории:
- **Ham** — обычные сообщения;
- **Spam** — нежелательные сообщения, включая рекламные и потенциально мошеннические рассылки.

Проект предназначен для демонстрации полного цикла разработки ML-модели: от подготовки данных и извлечения признаков до обучения, оценки качества и использования модели в интерактивном приложении.

## Используемые технологии

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Joblib

## Используемые модели

В проекте сравниваются три алгоритма классификации:
- Logistic Regression
- Linear Support Vector Classifier (LinearSVC)
- Multinomial Naive Bayes

Для экспериментов используются четыре набора признаков:
- TF-IDF;
- структурные признаки текста;
- TF-IDF с базовыми структурными признаками;
- TF-IDF со всеми структурными признаками.

## Установка и запуск

### Требования

- Python 3.10 или выше.
- Git.
- Операционная система Windows, Linux или macOS.

### 1. Клонирование репозитория

```bash
git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ>
cd detector
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

Активация в Linux/macOS:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск обучения

```bash
python train_model.py
```

После обучения в папках `models/` и `results/` сохраняются обученная модель, порог классификации, таблицы сравнения и графики.

### 5. Запуск приложения

```bash
python -m streamlit run app/app.py
```

После запуска Streamlit откроет интерактивное приложение в браузере.

Дополнительно формируются матрица ошибок и график важности признаков.



## Источник данных

В проекте используется датасет SMS Spam Collection, полученный с платформы Kaggle:

https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset

Первоначальный источник данных — UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/228/sms+spam+collection

Датасет содержит 5 574 SMS-сообщения на английском языке, размеченных на два класса:
- `ham` — обычные сообщения;
- `spam` — нежелательные сообщения.

Корпус сформирован из нескольких источников, включая Grumbletext, NUS SMS Corpus и другие исследовательские коллекции.

**Научная публикация:**

Almeida, T. A., Gómez Hidalgo, J. M., Yamakami, A. (2011). Contributions to the Study of SMS Spam Filtering: New Collection and Results. Proceedings of the 2011 ACM Symposium on Document Engineering.

В проекте исходный файл хранится в `data/sms.tsv`.

При подготовке данных удаляются точные дубликаты и сообщения с конфликтующими метками. После очистки в последнем эксперименте осталось 5 168 уникальных сообщений:
- 4 516 обычных сообщений;
- 652 спам-сообщения.

Файл `data/test.tsv` содержит независимую тестовую выборку, сформированную при первом запуске обучения.

## Условия использования данных

Датасет получен из публичной исследовательской коллекции. При использовании необходимо указывать первоначальный источник и научную публикацию авторов.

Условия распространения исходных данных следует проверять отдельно от лицензии исходного кода проекта.


## Ограничения

- Модель обучена на SMS-сообщениях на английском языке.
- Качество классификации зависит от состава и особенностей обучающего датасета.
- Классификация спама не является подтверждением факта мошенничества.
- Результаты экспериментов на тестовой выборке не гарантируют аналогичное качество на любых новых сообщениях.
